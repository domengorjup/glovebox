# Gas stations

Stations are created when you add a refuelling ("New station") or when you import a file. Manage them under **Manage → Gas stations**.

![Gas stations](../assets/screenshots/stations-desktop-light.png)

## Brands

A station has a name and an optional brand, for example station "Petrol Tržaška" with brand "Petrol". Statistics can group by brand to compare companies.

Brands are set **by hand only**. Glovebox never guesses a brand from a name. You can set a brand on one station, or select several stations and set the brand for all of them at once.

## Renaming

Open a station to change its name, brand or location text.

## Merging duplicates

Imports and typing errors often create duplicates ("PETROL Trzaska" and "Petrol Tržaška"). Use **Merge stations**: all refuellings of the duplicate move to the station you keep, and the duplicate is removed.
