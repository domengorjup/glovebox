# Glovebox

Self-hosted tracker for car running costs (fuel, maintenance, insurance, registration) with statistics, configurable CSV import with presets, a documented standard CSV format and full backups. Opens in the Home Assistant sidebar through Ingress and follows your Home Assistant theme.

Documentation: https://domengorjup.github.io/glovebox/
