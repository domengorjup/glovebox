# Contributing to Glovebox

Contributions are welcome. The easiest place to start is an **import preset** for an app you use: a short TOML file, no Python needed. Presets marked "never tested against a real export" also need someone to confirm them.

The full guide, including how to write and test a preset, is in the documentation: [Contributing](https://domengorjup.github.io/glovebox/dev/contributing/) (source: `docs/dev/contributing.md`).

Never commit real exports from your apps; they contain personal data. Tests use made-up fixtures.
